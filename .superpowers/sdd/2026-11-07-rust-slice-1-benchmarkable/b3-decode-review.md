## Important findings
1. **Valid JSON numeric overflow silently discards whole events** — `crates/omni-providers/src/openai/decode.rs:123–125` (`deep::parse` rejects numbers outside f64 range).
   Exact repro: `event: response.output_text.delta\ndata: {"delta":"keep me","ignored":1e309}\n\nevent: response.completed\ndata: {}\n\n`.
   Frozen: `blockDelta(text="keep me"), end(endTurn)`; Rust: only `end(endTurn)`. Thus even an unread extension field loses valid content. With text block framing, buffered text changes from `Infinity` to empty for delta=1e309; native done loses its merge and blockEnd; buffered native data stays empty.
   Terminal repro: `event: response.completed\ndata: {"response":{"usage":{"output_tokens":1e309}}}\n\n`. Frozen: End, outputTokens=Infinity (JSON null); Rust: retryable UPSTREAM `upstream stream ended before response completion`. ±1e309 both reproduce. **Third input class, distinct from parked nonnumeric counts and lone surrogates**; 6 streams ×4=24 differing runs.
2. **JS throwing coercions become successful Rust content/errors** — `decode.rs:90–93,184,191,300,311–313`; shared `crates/omni-ir/src/js.rs:35–53` hardcodes object/array conversion.
   Exact repro: `event: error\ndata: {"error":{"message":{"toString":null}}}\n\n`. Frozen: throws `TypeError: No default value`, emits no error event; Rust: `Error{code:UPSTREAM,message:"[object Object]",retryable:true}`. Same with toString=1 or [], including text deltas: Rust emits `[object Object]` then clean End, frozen throws before delta/End. 6 streams ×4=24 differing runs.
   Frozen adapter wraps those throws as `GatewayError{code:UPSTREAM,message:"openai codec decode threw",retryable:true,provider:"openai"}`, no upstream status; Rust never enters that path. Buffered collector comparisons preserve prefix-only frozen content versus Rust fabricated text; these are library outputs, not an observed HTTP error response.
   Related executed deep repro: `scripts/review-depth-reference.ts` generates delta=`[`×39990+`0`+`]`×39990 for function_call_arguments.delta. Frozen throws catchable RangeError; Rust emits partial="0" and continues. Same coercion-parity family; additional to the 1,236 shallow/framing runs.
